# Wildberries API Automation

Небольшой Python-проект для автоматизации работы с Wildberries API:

- создание карточек товаров из Excel
- загрузка фотографий по списку ссылок из Excel
- обновление остатков по XML-фиду поставщика

Проект сделан как практический рабочий набор утилит для интеграции с Wildberries в сценарии дропшиппинга.

---

## Что умеет проект

### 1. Создание карточек
Скрипт `src/create_cards.py`:

- читает Excel-файл с карточками
- собирает payload для Wildberries
- валидирует и нормализует часть полей
- в dry run режиме только проверяет данные
- в рабочем режиме отправляет карточки в API WB

### 2. Загрузка фотографий
Скрипт `src/upload_photos.py`:

- читает Excel-файл, где указаны `nmId` и ссылки на фото
- загружает фотографии в карточки WB
- поддерживает dry run режим
- повторяет запросы при временных ошибках

### 3. Обновление остатков
Скрипт `src/update_stocks.py`:

- скачивает XML поставщика
- парсит остатки
- сопоставляет товары поставщика с карточками WB
- обновляет остатки на нужном складе
- учитывает бизнес-логику безопасного остатка для дропшиппинга

## Dry Run режим

Во всех скриптах есть безопасный режим:

- `CARDS_DRY_RUN`
- `PHOTOS_DRY_RUN`
- `STOCKS_DRY_RUN`

Он позволяет проверить данные без отправки в WB.

---

## Бизнес-логика остатков

Для дропшиппинга:

- если остаток 0–2, в WB отправляется 0
- если товара нет в XML, остаток обнуляется при включенном флаге `ZERO_MISSING_IN_XML=true`

Это снижает риск продажи товара, который уже закончился у поставщика между обновлениями.
