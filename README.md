# Wildberries Automation System

Практический проект по автоматизации работы с маркетплейсом Wildberries.

Проект решает задачу управления ассортиментом в модели дропшиппинга:
массовое создание карточек, загрузка контента, синхронизация остатков и
контроль процессов.

------------------------------------------------------------------------

## Задача

При работе с маркетплейсом возникают типовые проблемы:

-   ручное создание карточек занимает значительное время
-   загрузка фотографий не масштабируется
-   остатки поставщика быстро устаревают
-   отсутствует прозрачный контроль обновлений

Цель проекта --- автоматизация операционного контура работы с
ассортиментом.

------------------------------------------------------------------------

## Реализованное решение

### 1. Создание карточек

Скрипт `create_cards.py`:

-   загрузка данных из Excel
-   подготовка payload для API Wildberries
-   проверка данных в режиме dry run
-   массовая отправка карточек

------------------------------------------------------------------------

### 2. Загрузка фотографий

Скрипт `upload_photos.py`:

-   загрузка изображений по ссылкам
-   пакетная обработка
-   повтор запросов при ошибках

------------------------------------------------------------------------

### 3. Обновление остатков

Скрипт `update_stocks.py`:

-   загрузка XML поставщика
-   сопоставление ассортимента
-   расчёт остатков
-   обновление склада через API

Реализована бизнес-логика:

-   безопасный остаток для дропшиппинга
-   скрытие товаров с низким остатком
-   обнуление отсутствующих позиций

------------------------------------------------------------------------

### 4. Автоматизация и мониторинг

-   запуск по расписанию (cron)
-   логирование выполнения
-   уведомления через API (email)

Сценарии:

-   ошибка --- уведомление сразу
-   успешное выполнение --- с ограничением частоты (hourly/daily)

------------------------------------------------------------------------

## Архитектура

-   Python-скрипты
-   конфигурация через `.env`
-   запуск через cron на VPS
-   интеграции через REST API
-   хранение состояния уведомлений

Система работает автономно и не требует ручного участия.
